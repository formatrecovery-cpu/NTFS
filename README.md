## 为什么Mac不能直接写入NTFS硬盘？

先说说这个问题的根源。NTFS是微软Windows系统的文件格式，苹果的Mac用的是APFS或者HFS+格式。虽然Mac能识别NTFS硬盘，但默认只给你"只读"权限——也就是说，你能看文件，但不能改、不能删、也不能往里复制新东西。

苹果这么做主要是出于系统稳定性考虑，毕竟微软没有完全公开NTFS的技术细节。但对于经常需要在Mac和Windows之间传文件的人来说，这就很不方便了。

这时候就需要一个专门的工具来"解锁"Mac的NTFS写入能力。市面上有不少这类软件，iBoysoft NTFS for Mac（中文名叫"赤友NTFS助手"）是其中口碑不错的一款，尤其是性价比这块比较突出。
